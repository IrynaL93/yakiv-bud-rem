# YAKIV.BUD.REM

Односторінковий сайт українською мовою на основі третьої, преміальної концепції: світлий фон, глибокий зелений, велика фотографія та шрифт із засічками.

## Запуск

Відкрийте index.html або виконайте: python -m http.server 8080

Без npm, сторонніх скриптів і збірки. styles.css — оформлення; script.js — мобільне меню та обробка помилок фото. Телефон і соцмережі вже підключені. Форми, CRM, аналітика та сторонні cookies не додані. Фото завантажуються із зовнішніх CDN.

## GitHub Pages

Створіть порожній репозиторій yakiv-bud-rem у потрібному обліковому записі GitHub. Завантажте в корінь усі файли цієї папки. У Settings → Pages оберіть Deploy from a branch → main → /(root). Адреса залежатиме від власника репозиторію.

Або після створення репозиторію прив’яжіть локальний git-проєкт до отриманого URL і виконайте git push -u origin main.

## Перед фінальним запуском

- Замінити ілюстративні фото на матеріали клієнта. Фото з соцмереж не завантажено через недоступність профілів у середовищі перевірки.
- Прибрати позначки ілюстративних фото тільки після заміни на підтверджені матеріали.
- За потреби додати логотип. Зараз використовується текстове написання назви.
- Після вибору домену додати canonical, og:url, локальне og:image і sitemap.
- Перевірити погодження клієнтом текстів. Статистику, відгуки, ціни та строки гарантії не вигадано.
